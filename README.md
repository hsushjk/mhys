# 梅花易数

一个基于传统梅花易数占卜法的纯前端网页。输入心中所惑，取三个数字，即可依数成卦，观爻知机。

---

## 简介

**梅花易数**是中国古代占卜术之一，相传为宋代邵雍所创。其法以数起卦，观象知机，通过数字推演天地万物的变化规律。

本项目以网页形式还原了这一传统占卜流程：用户输入所问之事，依次取三个 1~99 的数字，程序即按照梅花易数规则自动演算，得出本卦、动爻，并可进一步推演变卦与最终趋势。

> **事各有数，易为君子者卜，趋吉避凶，当循道枢。**
> **一卦一问，诚心则灵。今日一卦，不再复占。**

---

## 特性

- 遵循传统梅花易数取数成卦之法
- 演算过程逐步展示
- 六爻卦象以符号直观呈现，动爻高亮标示
- 支持推演变卦，展现事物发展趋势
- 涵盖 64 卦卦意解读与 6 种动爻建议
- 限占机制，每日限起三卦，同一问题三十日内不可复占
- 适配桌面端与移动端
- 纯原生 HTML/CSS/JavaScript，单文件即可运行（视具体使用方法，Cookie可能不会正常工作）

将 `index.html` 与 `favicon.png` 上传至任意静态服务器（如 GitHub Pages、nginx）即可。

## 使用说明

### 起卦步骤

| 步骤 | 内容 | 说明 |
|:---:|:---|:---|
| 1 | **立心** | 填写你所问之事，一句话描述心中所惑 |
| 2 | **取数 1** | 心中默念所问，随意想一个 1~99 的数字 |
| 3 | **取数 2** | 再取一个 1~99 的数字 |
| 4 | **取数 3** | 取第三个数字 |
| 5 | **推演** | 观看系统逐步演算，得出本卦 |
| 6 | **结果** | 查看卦象、动爻解读与综合建议 |

### 快捷操作

- `Enter` — 在当前步骤提交 / 查看结果 / 推演变卦
- `Esc` — 在结果页返回首页

### 演算规则

- **上卦** = 第一个数 ÷ 8 取余（余 0 作 8）
- **下卦** = 第二个数 ÷ 8 取余（余 0 作 8）
- **动爻** = 第三个数 ÷ 6 取余（余 0 作 6）
- **变卦** = 根据动爻位置，将本卦对应爻阴阳互换

代码结构清晰，主要包含：

- **`TRIGRAMS`** — 八卦符号映射
- **`GUA_MAP`** — 64 卦名映射表
- **`GUA_MEANING`** — 64 卦卦意解读
- **`DONG_ADVICE`** — 六爻动爻建议
- **`checkLimits` / `recordGua`** — 占卜次数限制逻辑
